Local time in time

For each t, every one of these definitions gives a number that converges to ℓt, and almost surely the convergence holds for all t at once. Here one duration 𝛿 sets all three scales by Brownian scaling: excursions of length at least 𝛿, a window of height 𝛿1/2, and dyadic intervals of length 2−n ≈ 𝛿. The sticky zero set

Run the same path on the sticky clock: 𝔜s = ℜσs with 𝜇 = 0.5, which waits at 0 for time 𝜇 per unit of local time. Its zero set Z𝔜 is again closed, with no isolated points and no interval, but now it has positive length: by time s the particle has spent time 𝜇ℓs at 0. Remove every excursion of 𝔜 of length at least 𝜀, as above (the excursions of 𝔜 have the same lengths as those of ℜ; only the waiting at 0 is new). What is left shrinks to Z𝔜, and the length of what is left by time s decreases to the time spent at 0 (teal): a fat Cantor set and its Cantor function.

The path is the talk's master path (Brownian motion from 0, 4000 steps, seed 878), refined to 1,024,000 steps by exact Brownian-bridge interpolation inside each step (fixed seed, so every viewer sees the same path). The refinement finds a slightly higher maximum, so here ℓ1 = 0.621, against 0.610 on the 4000-step grid. On a grid, the zero set is the set of grid times where B reaches a new maximum above x; it is drawn one pixel wide wherever a pixel column contains a zero.
